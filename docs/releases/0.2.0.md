# PURE RGB 0.2.0

本版将原生观片台加入工作流。完成修整后，先在灯板上查看单张或挑选整卷，再导出带 ICC 的 RGB16 TIFF。适用于 Apple 芯片 Mac，系统要求 macOS 14 或更新版本。

## 新功能与界面

- **独立观片台。** 第五步可打开当前照片、整卷或已有图像文件。整卷挑选会同步到工作台，导出移至第六步。原生观片器随 PURE RGB 提供。除尘检测与修复仍使用独立安装的 PURE Neg 后端。
- **XDR 观片。** 从 Mac 内建 XDR 显示器打开时默认全屏，Esc 退回窗口。外接 SDR 屏使用窗口，HDR 提示会随窗口所在屏幕更新。完整 HDR 观片体验需要 XDR 屏、合适的显示模式及 macOS 26 或更新版本。
- **可调工作台放大镜。** 点「100%」旁的放大镜，再点照片定位。默认镜片直径 288 点、倍率 3×；拖蓝点调大小，拖绿点、滚轮或捏合调倍率，最高 8×。
- **操作控件与应用菜单。** 参数滑块支持拖动和方向键微调，四个旋转与翻转按钮可从工具栏直接使用。玻璃面板以鲜明橙红标出重点操作。macOS 应用菜单新增「使用指南」「捐赠 StudioPURE 项目」「检查更新」，「关于 PURE RGB」可查看版本和捐助者。

## 修复与改进

- 确认除尘后调整曝光、白平衡等颜色参数，会在新成片上重新应用已确认蒙版。手工修补与橡皮擦结果随之保留。来源、引擎或输出几何改变时会提示重新审核。
- 修复从 Finder 打开时旧 Qt 插件缓存导致的闪退，以及从启动询问框新建空白项目后工作台无法显示的问题。启动时可载入旧任务、新建空白任务或取消。
- 修整启动对话框图标、圆角和键盘焦点，恢复转换引擎名称和方向按钮的可见性。观片台使用与工作台一致的彩色标识。
- 本机自建胶片标定留在个人目录。干净安装的 C-41 菜单包含 Generic C41 和 22 份随 NegPy 提供的配置。已导入的个人标定仍可在本机使用。

## 获取更新

0.1.1 会在启动后及持续运行期间每 24 小时检查一次新版。也可在旧版「设置 → 通用」中点「检查更新」。看到 0.2.0 提示后，打开发布页，退出旧版，使用 Apple 芯片 PKG 安装助手安装到「应用程序」，也可用访达解压 ZIP，双击同目录的「打开 PURE RGB.command」校验并打开应用。PKG 没有 Developer ID Installer 签名，应用使用本机临时签名，尚未通过 Apple 公证。若首次打开时 macOS 提示无法验证开发者，先核对发布页上的 SHA-256。如确定来自本项目，可在「系统设置 → 隐私与安全性」中选择「仍要打开」，按当时的系统提示确认。 [PKG 安装助手](https://github.com/easonzhangbin/PURERGB/releases/download/v0.2.0/PURE-RGB-0.2.0-macos-arm64.pkg) · [ZIP 应用包](https://github.com/easonzhangbin/PURERGB/releases/download/v0.2.0/PURE-RGB-0.2.0-macos-arm64.zip) · [Apple 官方说明](https://support.apple.com/zh-cn/102445)

有关六步流程、放大镜操作和 XDR 显示条件，请见[0.2.0 使用指南](https://github.com/easonzhangbin/PURERGB/blob/v0.2.0/docs/OPERATING_MANUAL.zh-CN.md)。
