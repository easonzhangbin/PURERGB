# PURE RGB 0.2.1

本版集中修复测量、批量导入、除尘保留和列表选择流程。已确认的除尘数据会随照片保存，后续调色、裁切、拉直、旋转与翻转后继续用于预览和完整 TIFF 导出。适用于 Apple 芯片 Mac，系统要求 macOS 14 或更新版本。

## 测量与平场

- **完整 NegPy 测量恢复为默认。** 分区密度测量保留为可选实验方案。白点、黑点及亮度／颜色截断使用原生参数规则，截断滑块采用 NegPy 的 −100 至 100 标尺。
- **区分计算基准与实际印相结果。** 自动印相密度／反差开启时，高级参数中的数值作为计算基准；更新后的画面左上角显示本次实际印相密度和 ISO-R 反差。切换胶片串扰配置时保留当前强度。
- **平场设置自动沿用。** 整卷中兼容的照片及后续导入组共用已选平场和强度，无需逐张重复应用。更换拍摄机位、镜头或光圈后，应重新选择匹配参考。
- 测量高级参数移到「绘制密度测量区」「减去不良区域」下方，默认展开，仍可手动收起。

## 批量导入、导出与卸载

- 文件夹或多选 RAW 导入后自动归组、排队处理，取消逐张点击「核对并导入」。列表先显示各组 RAW 缩略图，处理完成后替换为正式预览；未完成队列可在重开项目后继续。
- 无法自动识别片框时，先用中心区域完成测量，保留整张输出，之后可手动调整测量范围。
- 照片列表统一采用单选、多选和全选：单击单选，⌘／Ctrl 点击多选，Shift 点击连续选择，⌘A／Ctrl+A 全选；导出按所选照片处理。
- 全选或多选后，在选中的照片上右键卸载，可一次移除全部所选照片。卸载全部后会清空预览、示波器和导出选择，并清理对应导入队列。
- 从列表卸载会保留原始 RAW、调整、除尘记录及保存版本。修复已处理照片重新导入相同 RAW 时无法恢复原设置与版本的问题。

## 除尘与裁切

- **除尘作为隐藏修复数据保留。** 调色、切换步骤、切换兼容引擎和重开项目后继续沿用原审核选区。独立裁切、拉直、90° 旋转和翻转后，修复选区会映射到新画幅，供预览及完整导出使用。
- 原审核记录和蒙版保持不变，撤回几何编辑后可恢复原画幅。扩展裁切时，原审核范围外的新区域不会自动生成未经确认的修复。更换 RAW、平场或配准，以及改变透视／径向畸变后，仍需重新审核。
- 除尘画笔半径记住上一次设置，切换照片或重新打开软件后沿用，不再每次重置为 8。
- 移除「自动裁切 · 保留片基文字」「自动裁切 · 仅有效图像」两个识别不可靠的入口。手动裁切、拉直、旋转及已有裁切设置保留。

## 稳定性与提示

- 修复批量加入照片时，列表辅助功能缓存引发的崩溃；包含此前 macOS 窗口组件的稳定性修复。
- 修复系统给临时 TIFF 补充文件元数据时误报除尘数据改变的问题。文件内容仍通过 SHA-256 校验，修复区域外像素继续核验不变。
- 改进 PKG 打包流程，避免临时目录的 Finder 元数据影响安装后应用的签名校验。
- 提示浮层、错误、确认、更新和除尘提示统一水平、垂直居中；长中文按实际字体换行，修正末字单独换行及下方多余留白。

[PKG 安装助手](https://github.com/easonzhangbin/PURERGB/releases/download/v0.2.1/PURE-RGB-0.2.1-macos-arm64.pkg) · [ZIP 应用包](https://github.com/easonzhangbin/PURERGB/releases/download/v0.2.1/PURE-RGB-0.2.1-macos-arm64.zip) · [SHA-256 校验文件](https://github.com/easonzhangbin/PURERGB/releases/download/v0.2.1/SHA256SUMS-macos-arm64.txt)

支持自动检查更新的旧版会在启动后及持续运行期间每 24 小时检查一次正式新版，也可从应用菜单或「设置 → 通用」中选择「检查更新」。出现 0.2.1 提示后，打开[正式发布页](https://github.com/easonzhangbin/PURERGB/releases/tag/v0.2.1)，保存任务并退出旧版，按发布页说明安装。更新提示只负责通知，不会后台替换应用。

本版使用固定的 NegPy 0.68.0 核心。除尘检测与修复仍使用独立安装的 PURE Neg 后端。

PKG 没有 Developer ID Installer 签名，应用使用本机临时签名，尚未通过 Apple 公证；安装步骤见使用指南。Qt 6.11.2 的完整对应源码、修改文件和构建说明随 ZIP 提供，也可[单独下载](https://github.com/easonzhangbin/PURERGB/releases/download/v0.2.1/Qt-6.11.2-Corresponding-Source.tar.gz)。
