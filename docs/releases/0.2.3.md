# PURE RGB 0.2.3

本版提供可选的 RGB 灯光配平与拍摄曝光检查。可从「导入归组」或「采集工具」打开。适用于 Apple 芯片 Mac，要求 macOS 14 或更新版本。

## RGB 灯光配平

- **按实拍范围测量。** 载入同卷空白片基的 R、G、B 三张 RAW。橙框可单独移动和缩放，用来取同一块未曝光片基。蓝框圈住最终要保留的照片，确认该画幅后查看曝光建议。也可选择检查整幅 RAW。
- **查看配平与曝光建议。** 左侧显示三路片基的相对偏差和 ±5% 保持区。右侧独立检查原始 RAW 的曝光余量与剪切点数，并在数据足够时给出三路统一的快门试拍建议。
- **选择平场。** 可在配平窗口直接载入一张平场 RAW 或 NPZ 增益文件，也可选用已有平场或跟随项目配置。启用后用校正后的片基信号计算配平偏差。
- **保存和复用灯具设置。** 可按灯具原刻度填写 R、G、B，将灯光参考或完整分析报告保存为 TXT。载入同一灯具的参考并填写当前读数，即可查看调回参考值需要增减的刻度。
- **操作与原理说明。** 「配平指南」介绍选择片基、确认画幅、调整和复拍的顺序。「中英文说明」附两份柯达资料的摘要与原文链接。

## 安装与更新

保存工作并退出旧版，再用 PKG 安装助手安装。支持正式版更新检查的旧版会在启动后和持续运行期间检查更新。也可从应用菜单或「设置 → 通用」手动检查，点「查看更新」打开发布页下载。
