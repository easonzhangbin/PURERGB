# PURE RGB 0.2.5

[English release notes](#english)

本版加快有除尘记录的照片在切换色彩引擎、裁切、拉直和 100% 查看时的预览。适用于 Apple 芯片 Mac，要求 macOS 14 或更新版本。

## 工作台改进

- **切换引擎先看到新画面。** 在适应窗口且关闭 A/B 的情况下，切换 Nikon CMS 或 FlexColor 时，先显示该引擎的小尺寸预览，再更新精确预览。两次处理都会应用已确认的除尘蒙版。测量和采样条件一致时，Nikon CMS 与 FlexColor 可复用同一次处理中生成的采样结果。
- **裁切、拉直与翻转复用当前画面。** 打开裁切工具、确认裁切或拉直时，兼容的 Native 预览可复用已准备的画面和密度测量。只改 90° 旋转或翻转时，符合条件的预览直接调整方向，除尘范围随画幅映射。
- **100% 查看优先更新可见区域。** 支持的 Native 画幅可以直接处理当前视口，包含已拉直的画幅。关闭 A/B 时优先生成当前图，开启后再读取对应的参考区域。完整 TIFF 导出按原像素渲染并重放已确认除尘。

## 同组 RAW 实测

同组三张 Panasonic S1H RW2，合成 11,994 × 7,995 像素，照片已确认除尘。表内为 Build 70 和 Build 71 测试构建的后台处理计时，裁切与 100% 视口数字来自已准备好素材的测试。

| 操作 | Build 70 | Build 71 |
| --- | ---: | ---: |
| Native → Nikon CMS | 46.28 秒 | 首帧 0.75 秒，继续精化 8.39 秒 |
| Native → FlexColor | 68.21 秒 | 首帧 1.73 秒，继续精化 4.78 秒 |
| 打开裁切工具 | 32.11 秒 | 0.83 秒 |
| 确认裁切 / 拉直裁边 | 11.58 / 8.57 秒 | 0.49 / 0.61 秒 |
| 平移 1280 × 900 的 100% 视口，A/B 关闭 | 1.21–1.61 秒 | 0.21–0.44 秒 |

两种引擎的精确预览与旧构建的 RGB16 和 ICC 一致。拉直后的 100% 视口对照完整输出时，蒙版外像素和 ICC 一致。局部预览的蒙版内修补可能因可用的邻近像素范围而与完整导出有差异。首次解码、不同设置、缓存状态、A/B 对比以及需要全幅处理的效果会影响耗时。

保存工作并退出旧版，打开 PKG 安装助手。应用启动后及持续运行时会检查 GitHub 正式发布，也可在「设置 → 通用」手动检查。点击「查看更新」可前往发布页下载安装。

## English

This update speeds up engine switching, cropping, straightening, and 100% inspection for photos with approved dust repairs. Requires an Apple silicon Mac running macOS 14 or later.

### Workbench improvements

- **See the new engine sooner.** In Fit view with A/B comparison off, switching to Nikon CMS or FlexColor shows a small preview from the selected engine, then refines it. Both passes apply the approved dust mask. When metering and sampling settings match, the engines can reuse samples produced in one pass.
- **Reuse the current frame when adjusting geometry.** Supported Native previews reuse prepared pixels and density metering when opening Crop or confirming crop and straighten edits. Eligible 90° rotations and flips update the existing preview, and the approved dust mask follows the frame.
- **Update the visible region at 100%.** Supported Native frames, including straightened frames, can render a viewport directly. With A/B off, PURE RGB renders the current image first and reads the matching reference region when comparison is opened. Full-resolution TIFF exports apply the approved dust repairs at original pixel size.

### Same-RAW benchmark

Three exposures from a Panasonic S1H formed an 11,994 × 7,995 image with approved dust repairs. The table compares worker processing times in test Builds 70 and 71. Crop and viewport tests used a prepared source.

| Action | Build 70 | Build 71 |
| --- | ---: | ---: |
| Native → Nikon CMS | 46.28 s | 0.75 s to first frame, then 8.39 s to refine |
| Native → FlexColor | 68.21 s | 1.73 s to first frame, then 4.78 s to refine |
| Open Crop | 32.11 s | 0.83 s |
| Confirm crop / straighten and trim | 11.58 / 8.57 s | 0.49 / 0.61 s |
| Pan a 1280 × 900 viewport at 100%, A/B off | 1.21–1.61 s | 0.21–0.44 s |

The refined Nikon CMS and FlexColor previews matched the older build's RGB16 pixels and ICC profiles. Straightened 100% test viewports matched the full export outside the dust mask and used the same ICC profile. Repairs inside the mask may differ in viewport previews because fewer neighboring pixels are available. Timings vary with initial RAW decoding, settings, cache state, A/B comparison, and effects that require the full frame.

### Installation and updates

Save your work, quit the previous version, and open the PKG installer. PURE RGB checks for stable GitHub releases after startup and periodically while running. You can also check under Settings → General. The update notice opens the release page for download and installation.

The package has no Developer ID Installer signature. The app is ad hoc-signed and has not been notarized by Apple.
