# PURE RGB 0.2.4

新版更新 NegPy 原生彩色模式的高光找回与印相曝光，并缩短拖动调色、切换引擎和裁切后等待画面的时间。适用于 Apple 芯片 Mac，要求 macOS 14 或更新版本。

## 负片高光与印相曝光

- **从负片密度保留高光。** 「高光找回」读取相纸曲线前的三路负片密度，把接近相纸白的亮部平滑映射到 SDR。「转换调色」中可用 0–100% 滑杆调整强度。
- **调明暗时保留颜色。** 「印相曝光（EV）」使用负片密度计算亮度，再沿用原来的 RGB 色彩比例。降低曝光可展开 RAW 中已记录的亮部细节。用同组三张 RW2 验证了 0 EV 和 −0.5 EV，精细预览与各自的 16 位 TIFF 导出像素及 ICC 一致。
- 旧项目会提示重新生成仍使用旧版非零印相曝光的完整版本。

## 预览与性能

- **拖动先出画面，松手再精化。** 调色时优先处理当前轻量预览，避免过时的预览请求占住绘图。部分路径直接交接 RGB16，减少临时 TIFF、显示转换与反复绘制的开销。
- **复用测量和源文件。** NegPy 原生、Nikon CMS 与 FlexColor 的预览可复用已解码的素材、有效密度测量或已准备的色彩结果。按需读取 A/B 参考图，100% 查看时可读取已保存 TIFF 的可见区域。
- **裁切更早绘制。** 确认裁切后可先显示新画幅，再完成精确预览。相同测量区可复用已有的密度结果。

在 Apple M1 Max 上，用同组三张 Panasonic S1H RAW 对照这一轮的优化前后测试构建。确认裁切后约 **0.10 秒**出现新画幅，首次切换 Nikon CMS 的精确预览由约 **14.9–15.3 秒**降至 **10.4–11.1 秒**。实际耗时随素材大小、设置、缓存和硬件而变。

## 采集与测量

- 初始密度测量取已识别有效画幅中心约 80% 的面积。识别不确定时，可框选实际画幅后再测量。
- 可选的 RGB 灯光配平可在三张 RAW 中寻找共同的片间空隙、提出橙框建议，并交由用户调整和确认。
- 首次使用介绍增加分章图文、实拍对照、量区示意和可展开的公式说明。

## 安装与更新

保存工作并退出旧版，打开 PKG 安装助手。应用在启动后及持续运行时检查 GitHub 正式发布，也可从「设置 → 通用」手动检查，并从发布页下载安装。

安装包沿用上一版的签名方式。PKG 没有 Developer ID Installer 签名，应用使用本机临时签名，尚未通过 Apple 公证。
