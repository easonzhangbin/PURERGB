# Third-party sources

- [NegPy 0.68.0](https://github.com/marcinz606/NegPy/tree/d8123a9b2a18fdaab5941347a91e402fa936d3dc) at commit `d8123a9b2a18fdaab5941347a91e402fa936d3dc` is the GPL-3.0 base for the RAW, RGB-scan and negative-print pipeline. The installer checks out its original [license](licenses/NegPy-GPL-3.0.txt), [NOTICE](https://github.com/marcinz606/NegPy/blob/d8123a9b2a18fdaab5941347a91e402fa936d3dc/NOTICE.md) and dependency lockfile.
- [cool-colors](https://github.com/rohanpandula/cool-colors/tree/74ffceb79e6e976858d9bffddfeefddba626378f) by Rohan Pandula at commit `74ffceb79e6e976858d9bffddfeefddba626378f` provides the reference density inversion and Nikon downstream research. The [MIT source license](licenses/cool-colors-LICENSE.txt) expressly excludes the original Nikon data and profiles. The installer obtains the source-only checkout. The CMS route can validate matching user-supplied local files.
- [flexcolor-tool](https://github.com/rohanpandula/flexcolor-tool/tree/04e745a2fde3559acb2d4f194b7a192150b26f5c) contributors at commit `04e745a2fde3559acb2d4f194b7a192150b26f5c`. PURE RGB calls supported curve construction, contrast/brightness and negative gamma stages. See the [MIT license](licenses/flexcolor-tool-LICENSE.txt). Factory DLLs, film profiles, device LUTs and ICC files remain separate.
- [nkscan](https://github.com/activexray/nkscan/tree/f971cfd8efe89f6e02507c80b0945206fdaf0bcd) at commit `f971cfd8efe89f6e02507c80b0945206fdaf0bcd`. PURE RGB ports portions of the metering and parameter arithmetic under the [MIT option](licenses/nkscan-MIT.txt). Original scanner characteristic tables are outside this release.
- [PURE Neg](https://github.com/easonzhangbin/PURENeg) is an independent optional application. PURE RGB uses the installed backend through its CLI. The backend, runtime and models are distributed separately by that project under its own [notices](https://github.com/easonzhangbin/PURENeg/blob/main/THIRD_PARTY_NOTICES.md).

Bootstrapping installs the Python and Rust dependencies pinned by NegPy, plus the PyObjC Core, Cocoa and Quartz bridges for native system integration. The distribution consists of PURE RGB source and its interface assets and documentation. The repository includes the dependency setup and local app build scripts.
